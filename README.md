# Núcleo PC — Sistema de Gestão e Loja Virtual

## Sobre o projeto

O Núcleo PC é um sistema web desenvolvido para auxiliar na gestão de uma loja de informática e disponibilizar uma loja virtual para seus clientes.

O sistema reúne funcionalidades administrativas e recursos de comércio eletrônico, permitindo organizar produtos, estoque, vendas e pedidos.

## Funcionalidades

### Painel administrativo
- Cadastro e gerenciamento de produtos.
- Gerenciamento de categorias e fornecedores.
- Controle de estoque e entradas de mercadorias.
- Registro e acompanhamento de vendas.
- Gerenciamento de usuários.
- Consulta de mensagens enviadas pelos clientes.
- Consulta de relatórios administrativos.

### Loja virtual
- Visualização e pesquisa de produtos.
- Consulta aos detalhes dos produtos.
- Carrinho de compras.
- Cadastro e login de clientes.
- Finalização de pedidos.
- Fluxos representativos de pagamento por Pix, cartão e boleto.
- Consulta de pedidos.
- Formulário de contato.

## Tecnologias utilizadas

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- PDO
- Git e GitHub

## Arquitetura

O sistema utiliza o padrão MVC (Model-View-Controller), que organiza a aplicação em camadas responsáveis pelo controle das requisições, pela lógica de dados e pela apresentação das interfaces.

## Requisitos para execução

- PHP compatível com a versão utilizada no projeto.
- MySQL.
- Servidor web Apache.
- XAMPP ou ambiente equivalente.
- Navegador atualizado.

## Como instalar e executar

1. Clone ou baixe este repositório.
2. Coloque os arquivos no diretório do servidor web local.
3. Inicie o Apache e o MySQL.
4. Crie o banco de dados e importe o script SQL disponibilizado no projeto.
5. Confira e ajuste as configurações de conexão com o banco de dados.
6. Acesse a aplicação pelo navegador utilizando o endereço local correspondente à estrutura do projeto.

Consulte a documentação do projeto para obter detalhes sobre a configuração do banco de dados e a execução do sistema.

## Banco de dados

O sistema utiliza MySQL para armazenar informações relacionadas aos produtos, usuários, clientes, estoque, vendas e pedidos.

O script de criação do banco de dados deve ser utilizado conforme as instruções e os arquivos disponibilizados neste repositório.

## Observação sobre pagamentos

As funcionalidades de pagamento por Pix, cartão e boleto são representativas e destinadas à demonstração do fluxo de compra. O sistema não processa cobranças financeiras reais.
